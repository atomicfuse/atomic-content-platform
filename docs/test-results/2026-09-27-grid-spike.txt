NOTE: `pnpm build` initially failed before this spike could run:
  src/lib/grid/normalize.ts (2:41): "GRID_DEFAULTS" is not exported by "../shared-types/dist/index.js"
Root cause: normalize.ts (Task 2) imported GRID_DEFAULTS / GRID_CARD_DEFAULTS / GRID_CARD_OPTIONS as
VALUES from '@atomic-platform/shared-types'. shared-types emits CJS re-exports via
`Object.defineProperty(exports, "X", { get(){...} })`, which Rollup's production bundle (astro build)
cannot statically resolve as a named ESM export — this is the exact landmine already documented on
LAYOUT_DEFAULTS in packages/site-worker/src/lib/config.ts. Vitest/dev builds don't hit this (different
module transform), which is why the existing unit tests passed despite the broken production build.
Fix applied (in src/lib/grid/normalize.ts, outside Task 3's nominal file list but required to unblock
this gate): inlined the three constants locally (verbatim values from shared-types/src/grid.ts) and
kept only type-only imports from shared-types. Re-ran the full unit suite (351/351 still pass) and
`pnpm build` now succeeds. See task-3-report.md self-review section for detail.
